# Echoes Beyond Earth: A Hardware Time Capsule

An interactive educational website created for the **NASA Space Apps Challenge**. The project introduces school-age space enthusiasts to hardware placed across the Solar System and explains the science made possible by each machine.

## Live Project

[Explore Echoes Beyond Earth](https://7-echo.github.io/Echoes-Beyond-Earth-A-Hardware-Time-Capsule/)

## About the Project

Since the 1960s, spacecraft and scientific instruments have been left on the Moon, operated on Mars, and sent into deep space. **Echoes Beyond Earth** presents selected examples as a simple interactive journey.

The project covers:

- **Apollo 11 Passive Seismic Experiment** on the Moon
- **Curiosity rover** on Mars
- **Voyager spacecraft** in interstellar space
- **New Horizons spacecraft** in the Kuiper Belt

Visitors can filter missions by destination, follow a timeline, learn short scientific facts, and answer an interactive quiz.

## Main Features

- Responsive design for computers, tablets, and phones
- Mission cards organized by destination
- Interactive Moon, Mars, and Deep Space filters
- Space-exploration timeline from 1969 to 2019
- Short educational quiz
- Direct links to official NASA resources
- No external framework or server required

1. Download or clone this repository.

```bash
git clone https://github.com/7-echo/Echoes-Beyond-Earth-A-Hardware-Time-Capsule.git
cd Echoes-Beyond-Earth-A-Hardware-Time-Capsule
```

No installation or additional dependencies are required.
